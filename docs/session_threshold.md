# Session Threshold Decision

## Метод

Построена гистограмма inter-event gap в log10-шкале (минуты) по всем 3 месяцам данных и всем пользователям. Вычисление пофайловое по датам:
для каждой даты считаются внутридневные гэпы + межсуточные гэпы
Подробнее в ноутбуке `research/intent_gap.ipynb`

![gap histogram](gap_histogram.png)

## Обоснование порога 35 минут

### 1. Данные: долина гистограммы

На гистограмме видны две 2 явные "долины" 35 min и 266 min. Следующее "долины" скорее фейковые, видно по графику

Выберем 35 минут как точку наименьшей ошибки разбиения, так как 266 минут звучит нереалистично. Может отражать скорее то как скоро пользователь зайдет повторно:
- порог **левее** - реальные сессии дробятся (пользователь ненадолго отвлёкся)
- порог **правее** - разные визиты склеиваются в одну сессию


## Результат

```python
SESSION_GAP_MIN = 35  # minutes
```

Сессия начинается заново, если пауза между событиями одного пользователя
превышает 35 минут
